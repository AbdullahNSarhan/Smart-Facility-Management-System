# Features and Modules — LCI-SFM (`2.0.0-rc.1`)

Every feature below has been verified directly against the frontend, backend, SQLite, and MQTT source code—never assumed from UI labels alone.

---

## 1. Module & Feature Implementation Matrix

| Module / Feature | Status | Responsible Components | Key APIs / Channels | Verification Notes |
|---|---|---|---|---|
| **Public Appliance Landing (`/`)** | **Fully Implemented** | `frontend/pages/landing.js`, `apiRoutes.js` | `GET /api/public/info` | Renders local posture, SQLite health, and isolated simulator mode banner (`info.simulation === true`). |
| **Authentication, Sessions & CSRF** | **Fully Implemented** | `login.js`, `store.js`, `auth.js`, `sqliteRepository.js` | `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/session` | `scrypt` password verification, `HttpOnly; SameSite=Strict` cookie (`lci_sid`), SHA-256 token verifier in SQLite, 30m idle / 8h absolute TTL, timing-safe `X-CSRF-Token`, login rate-limiting, WS disconnect on logout. |
| **Role-Based Access Control (`Admin` / `Viewer`)** | **Fully Implemented** | `auth.js`, all backend routers, `shell.js`, page modules | All `/api/*` & `/api/v1/*` routes | Enforced server-side on every route (`requireAuth` / `requireAdmin`) and reflected in UI navigation, quarantine/profile notices, and action controls. |
| **Multi-Room Topology Management** | **Fully Implemented** | `rooms.js`, `releaseOperations.js`, `operationsRoutes.js` | `GET/POST /api/v1/rooms`, `GET/PUT /api/v1/rooms/:id`, `POST .../archive`, `POST .../restore` | Supports create (`?action=create`), edit (optimistic `version` 409 check), search/filter, archive, confirmed restore, environmental summary strip, recent room commands, and moving devices across rooms with telemetry history preserved. |
| **Generic Device & Endpoint Registry** | **Fully Implemented** | `devices.js` (4-Step Wizard), `widgets.js`, `releaseOperations.js`, `operationsSchemas.js` | `GET/POST /api/v1/registry`, `GET/PUT /api/v1/registry/:id`, `POST .../move`, `.../archive`, `.../restore`, `.../maintenance`, `GET .../history` | Supports up to 512 active devices; preserves full endpoint metadata & `min_value`/`max_value` bounds on edit; configurable `1–1440` min Maintenance modal with audited reason; capabilities `SENSOR` (`NUMBER`/`BOOLEAN`), `SWITCH` (`ENUM`/`BOOLEAN`), `ACCESS` (`ENUM`), `CAMERA` (`MEDIA`/`BOOLEAN`). |
| **Pending Device Quarantine & Manifest Drift** | **Fully Implemented** | `mqttClient.js`, `releaseOperations.js`, `devices.js`, `overview.js` | `lci/v1/devices/+/heartbeat`, `GET /api/v1/pending-devices`, `POST .../dismiss` | Unregistered `MQTT_V1` heartbeats are quarantined in `pending_devices` (`PENDING`/`APPROVED`/`DISMISSED` filters and confirmed dismissal in `/app/devices`). Registered devices announcing changed/missing/extra endpoints raise `manifest_drift` warnings without mutating approved schemas. |
| **MQTT v1 Telemetry & Per-Endpoint Freshness** | **Fully Implemented (Server & Console)** | `mqttClient.js`, `releaseOperations.js`, `wsServer.js`, `store.js`, `devices.js`, `utils.js` | `lci/v1/devices/+/telemetry`, `WS /ws/telemetry`, `GET .../endpoints/:key/history`, `GET /api/v1/registry/:id/history` | Validates schema, boot/seq replay protection, rejects retained frames, updates `device_frames`, `device_observations`, and per-endpoint `device_endpoint_state`, broadcasts live over `/ws/telemetry`, renders recent device frames, and plots timestamp-proportional SVG trend & digital step charts (`100`/`250`/`500` limits) + CSV export. *(Physical firmware pending.)* |
| **Legacy Environmental Telemetry (`lecf/env/telemetry`)** | **Partially Implemented (Legacy Caveat)** | `mqttClient.js`, `sqliteRepository.js`, `releaseOperations.js`, `operations.js` | `lecf/env/telemetry`, `GET /api/telemetry/aggregate` | `GET /api/telemetry/aggregate` (`1h`/`24h`/`7d` × `5m`/`15m`/`1h`) is surfaced in `/app/events` → `Env Telemetry` with min/avg/max rollup band charts and KPIs (intentionally scoped to legacy `environmental_telemetry`, separate from `device_frames`). Backend `_handleEnvTelemetry` retains legacy synthetic smoke mapping (`650`/`120`). |
| **Remote Switch & Legacy Actuation Commands** | **Fully Implemented (Server & Console)** | `widgets.js`, `releaseOperations.js`, `commandCoordinator.js`, `mqttClient.js` | `POST /api/v1/registry/:id/commands`, `POST /api/command`, `lci/v1/devices/:id/{command,ack}`, `lecf/{access,env}/command{/ack}` | Non-retained QoS 1 commands with 5s expiry, audit-before-publish, correlated `/ack` verification (`PUBLISHED` → `ACKNOWLEDGED` → `STATE_REPORTED`/`STATE_CONFIRMED` / `TIMED_OUT` / `FAILED`), disabled during maintenance or stale device state. *(Physical actuator firmware pending.)* |
| **HTTP JSON Sensor Probe (`HTTP_JSON_V1`)** | **Partially Implemented (Manual Only)** | `devices.js`, `releaseOperations.js` | `POST /api/v1/registry/:id/probe` | Admin-triggered manual HTTP GET (`3s` timeout, `32 KiB` max, `redirect: 'manual'`). **No automatic background polling scheduler** exists for `HTTP_JSON_V1` devices. |
| **Authenticated Camera Snapshot Proxy (`CAMERA_JPEG`)** | **Fully Implemented (Server Proxy & UI)** | `widgets.js`, `cameraSnapshot.js`, `operationsRoutes.js`, `managementRoutes.js` | `GET /api/v1/registry/:id/snapshot`, `GET /api/v1/devices/node3/snapshot` | SSRF-bounded fetch to literal RFC1918 IP (`4s` timeout, `2 MiB` max, no redirects, `image/jpeg` + `FFD8..FFD9` marker check), rendered via browser `Blob` URL with automatic `URL.revokeObjectURL` cleanup on unmount/re-render and an explicit simulation placeholder when `simulation === true`. |
| **Biometric Face Recognition & Live MFA Audit** | **Partially Implemented (Audit & WS UI Ready; No Vision Service)** | `mqttClient.js`, `wsServer.js`, `operations.js`, `mosquitto/acl` | `lecf/access/mfa_face`, `lecf/access/state`, `GET /api/logs/camera_events`, `WS /ws/mfa` | Backend ingests `lecf/access/mfa_face` and `lecf/access/state`, logs to `camera_events`/`access_logs`, and broadcasts on `/ws/mfa`; `/app/events` → `Camera Events` displays persisted records and live-refreshes via `/ws/mfa`. **Missing:** No Python/OpenCV Vision edge service exists in the repo. |
| **Stateful Alarms & Deterministic Rules** | **Fully Implemented** | `operations.js`, `releaseOperations.js`, `operationsRoutes.js` | `GET/POST/PUT /api/v1/rules`, `GET /api/v1/alarms`, `GET /api/v1/alarms/:id`, `POST .../{acknowledge,resolve}` | Supports `SENSOR` rules (`THRESHOLD_HIGH`, `THRESHOLD_LOW`, `BOOLEAN_TRUE`, `BOOLEAN_FALSE`) with strict hysteresis validation, dwell timers (`hold_s`, `clear_hold_s`), room/device/date filters, pagination, `?alarm_id=` deep-linked timeline drawer, live refresh, and comment-audited Ack/Resolve. |
| **Scoped Notification Center & Audio Cues** | **Fully Implemented** | `operations.js`, `shell.js`, `store.js`, `releaseOperations.js`, SQLite triggers | `GET /api/v1/notifications`, `PUT .../read`, `PUT .../read-all`, `GET/PUT /api/v1/notification-preferences`, `WS /ws/notifications` | Audience-scoped (`ALL`, `ADMIN`, private `USER`), room/device filters, `Inspect Alarm` deep-links, per-account read receipts (`notification_reads`), `through_id` mark-all-read, WebSocket push, and user-gesture-gated Web Audio critical alert chime. |
| **Events & Audit Explorer** | **Fully Implemented** | `operations.js`, `apiRoutes.js`, `managementRoutes.js`, `sqliteRepository.js` | `GET /api/logs/:table`, `GET /api/v1/commands`, `GET /api/v1/management-audit` | Displays allowlisted `access_logs`, `camera_events`, `environmental_telemetry` (with `/api/telemetry/aggregate` rollups), `system_errors`, `commands`, and (Admin) `management_audit` with curated columns, `100`/`250`/`500` row limits, slide-over detail drawer, and formula-safe CSV export. |
| **Interactive Network & Connectivity Map** | **Fully Implemented** | `network.js`, `operationsRoutes.js`, `apiRoutes.js` | `GET /api/health/ready`, `GET /api/v1/diagnostics`, `GET /api/v1/registry` | Local SVG topology graph (Browser → Backend → SQLite / MQTT → Devices) with keyboard/click node inspector and Device Connectivity Matrix. |
| **Dashboard Operator Management & Credential Rotation** | **Fully Implemented** | `admin.js`, `apiRoutes.js`, `managementRoutes.js`, `sqliteRepository.js` | `GET /api/logs/system_users`, `POST /api/v1/operators`, `POST /api/users/role`, `POST /api/users/delete`, `POST /api/auth/admin-profile` | Create operator, promote/demote role (with session-revocation confirmation on desktop & mobile), delete operator (with last-Admin protection), and verified Admin credential rotation (`currentPassword` verification + revocation of all other sessions). |
| **Facility Settings & Data Retention Policy** | **Fully Implemented** | `admin.js`, `operationsRoutes.js`, `managementRoutes.js`, `releaseOperations.js` | `GET/PUT /api/v1/facility`, `PUT /api/v1/retention`, `GET/PUT /api/v1/settings` | Configures Facility Profile, Data Retention Policy (`7–365` days pruning `notifications` and `device_frames` while preserving alarms & audits), and Baseline Node Destinations + Display Thresholds (`room_name`, `temperature_warning`, `gas_warning_raw < gas_critical_raw`). |
| **Facility People, RFID/PIN Credentials & Reader Enrollment** | **Partially Implemented (Console Complete; No Edge Policy Sync)** | `admin.js`, `facilityManagement.js`, `managementRoutes.js` | `GET/POST/PUT /api/v1/people`, `POST .../credentials`, `PUT /api/v1/credentials/:id`, `POST .../enrollment-sessions`, `lecf/access/enrollment/{command,event}` | Console supports occupant create/edit/suspend/activate, search & pagination, masked RFID UIDs (`masked_uid`), scrypt 6-digit PINs, confirmed Block/Revoke transitions (`ASSIGNED` → `BLOCKED` / `REVOKED`), and 45s reader enrollment modal. **Limitation:** Credentials remain `PENDING_DEVICE_SYNC` until edge controller sync firmware is implemented. |
| **Host MQTT Identity Provisioning** | **Fully Implemented** | `scripts/provision-mqtt-device.sh`, `devices.js`, `releaseOperations.js` | Host CLI + `PUT /api/v1/registry/:id/mqtt-identity` | Host CLI safely adds/rotates/revokes per-device `%u` credentials in `mosquitto/passwd`, verifies ACLs, writes `0600` `.cred` files, and reloads Mosquitto via `SIGHUP`; UI tracks `PROVISIONED`/`UNPROVISIONED` status. |
| **Isolated Software Simulator** | **Fully Implemented** | `scripts/simulator.mjs`, `admin.js`, `releaseOperations.js` | `npm run simulate` (`127.0.0.1:3101`), `POST /api/v1/simulator` | Runs against isolated `data/simulator/lci_sfm.sqlite`, hard-blocked in `NODE_ENV=production`, supports `normal`, `alarm`, `offline`, and `command-failure` scenarios. |
| **Deployment, Backup & Air-Gap Offline Bundles** | **Partially Implemented (Minor Offline Script Gaps)** | `install.sh`, `update.sh`, `install-offline.sh`, `update-offline.sh`, `scripts/*`, `db/backup.js` | Host CLI scripts | Online `install.sh` and `update.sh` (tested in CI) are mature and idempotent; offline scripts verify SHA-256/OpenSSL signatures and rollback, with minor gaps around legacy MQTT users in `install-offline.sh` and TLS override preservation in `update-offline.sh`. |
