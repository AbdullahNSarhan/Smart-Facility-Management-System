            Technical Details · Hardware Bus & PoE Architecture
            
    
              Network Layer: Wired CAT6 IEEE 802.3af/at PoE (W5500 Ethernet).
              Node 1 Bus: ESP32-S3-POE with MFRC522 on isolated FSPI (SPI2), 4x4 matrix keypad, and opto-isolated 12V fail-safe solenoid relay.
              Node 2 Cadence: Polls DHT22, MQ-2 ADC, and LDR every 2,000 ms via non-blocking millis() and publishes to lecf/env/telemetry.
              Node 3 Vision: ESP32-S3-POE-CAM wakes on PIR interrupt to serve http://<ip_node3>/capture.jpg.
